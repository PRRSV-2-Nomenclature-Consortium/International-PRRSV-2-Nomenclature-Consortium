# International PRRSV-2 Nomenclature Consortium
The primary purpose of the International PRRSV-2 Nomenclature Consortium is curate the lineage nomenclature of PRRSV-2 through time. This repository hosts materials to aid in that mission. Materials include:
* [New nomenclature proposal template](https://github.com/PRRSV-2-Nomenclature-Consortium/International-PRRSV-2-Nomenclature-Consortium/blob/main/IPNC_proposal_template_v1.pptx)
* [Reference sets for phylogenetic analysis](https://github.com/PRRSV-2-Nomenclature-Consortium/International-PRRSV-2-Nomenclature-Consortium/tree/main/reference_sets)
* [Informational guides on standards of nomenclature acceptence](https://github.com/PRRSV-2-Nomenclature-Consortium/International-PRRSV-2-Nomenclature-Consortium/blob/main/ipnc_standard_treebuilding_v1.pptx)
